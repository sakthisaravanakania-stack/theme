
✨ A simple and responsive *Theme Switcher* built using *React.js*.  
Users can easily switch between *Light Mode ☀️* and *Dark Mode 🌙* with a single click.

## 🚀 Features

- ☀️ *Light Theme* – Switch to a clean white background
- 🌙 *Dark Theme* – Switch to a dark background
- ⚡ *Instant Theme Switching*
- 🎨 Simple & Clean UI
- 📱 Responsive Design
- ⚛️ Built with React useState

## 🛠️ Technologies Used

- ⚛️ React.js
- 🎨 CSS3
- 💻 JavaScript
- ⚡ Vite

## 🧠 React Concept Used

### useState()

The useState() hook is used to manage the current theme.

```jsx
const [theme, setTheme] = useState("light");
When the Light button is clicked:
setTheme("light");
When the Dark button is clicked:
setTheme("dark");
🎯 How It Works
☀️ Light Button
       ↓
 setTheme("light")
       ↓
 White Background 🤍

🌙 Dark Button
       ↓
 setTheme("dark")
       ↓
 Black Background 🖤
